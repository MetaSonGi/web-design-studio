# 웹 디자인 스튜디오

비즈니스 정보를 입력하면 "AI slop(뻔한 AI 느낌)" 없는 개성 있는 랜딩페이지를 만들어주는 웹앱.
Impeccable/Taste 아이디어의 브라우저판 — 큐레이션된 디자인 시스템 + 비주얼 월드 프리셋.

## 사용법

1. **비즈니스 정보 입력**: 비즈니스명, 한 줄 소개, 설명 문단, 버튼 문구·링크, 이메일, 특징 3개
2. **가격표 · FAQ 입력**: 3단계 플랜(플랜 2가 추천 강조)·가격·혜택, 자주 묻는 질문 4개
3. **비주얼 월드 선택** (6종): 미니멀 모노 / 브루탈리스트 / 플레이풀 팝 / 엘레강스 세리프 / 테크 다크 / 페이퍼 질감
4. **타이포그래피**: 제목 폰트 6종(고딕·명조·둥근·모노·손글씨·강조고딕), 제목 크기(작게/보통/크게), 본문 행간(1.40~2.00)
5. **색상 커스텀**: 배경색·텍스트색·포인트색 직접 변경 (월드 기본값에서 시작, 되돌리기 버튼)
6. **이미지 업로드**: 히어로 배경 1장 + 갤러리 3장. 미리보기 즉시 반영, 다운로드 HTML에 base64 내장
7. **섹션 구성**: 히어로·특징·가격표·갤러리·고객 후기·FAQ·CTA 배너·연락처/푸터 on/off
8. **미리보기**: 입력 즉시 실시간 렌더링. 🎲 랜덤 변형 버튼으로 같은 월드 내 레이아웃 변형 (3종)
9. **HTML 다운로드**: 미리보기와 동일한 독립 실행 `landing-page.html` 저장 (CSS 인라인 + 스크롤 리빌·FAQ 아코디언용 최소 스크립트 포함)

데스크탑/모바일 미리보기 전환 지원. 스크롤 리빌 애니메이션·버튼 호버·부드러운 스크롤은 미리보기와 다운로드본 모두에 적용됩니다.

데스크탑/모바일 미리보기 전환 지원.

## 특징

- 외부 의존성 0개 (CDN 없음, 시스템 폰트만 사용) — 오프라인에서도 동작
- 흔한 보라 그라데이션·똑같은 3카드 나열 금지: 월드마다 팔레트·타이포·모서리·장식이 확연히 다름
- 입력값 XSS 방지: 텍스트는 escape, 링크는 `javascript:` 차단, 업로드 이미지는 `data:image/*;base64,` 형식만 허용
- 이미지: 파일당 5MB 초과 시 등록 거부(토스트 안내), 전체 8MB 초과 시 다운로드 차단
- 갤러리·후기는 샘플 플레이스홀더 (실제 이미지/문구로 교체해서 사용)

## 실행

`index.html`을 브라우저에서 열거나 GitHub Pages로 배포하면 바로 사용 가능합니다.
